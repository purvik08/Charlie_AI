# Complete Migration Prompt: Replace Ollama with llama.cpp

You are a senior AI systems engineer and software architect.

Your task is to completely remove Ollama from my project and replace it with a native llama.cpp-based inference engine while preserving all existing functionality, improving performance, reducing latency, minimizing resource usage, and making the system more modular and reliable.

## Primary Objectives

1. Remove **every dependency on Ollama** from the project.
2. Replace all inference with **llama.cpp**.
3. Preserve every feature currently implemented.
4. Improve architecture wherever possible.
5. Reduce inference errors and failure points as much as practically possible through validation, structured outputs, retries, and robust error handling.
6. Keep the entire system fully offline.
7. Maintain compatibility with my existing downloaded models.
